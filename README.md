# 뉴스 스크랩

키워드를 넣으면 **중앙언론 10곳**과 **대구·경북 지역언론 6곳**의 관련 기사를 나눠서 모아 보여주고,
등록한 키워드에 새 소식이 생기면 알림을 보내 주는 Windows 프로그램입니다.

## ⬇️ 다운로드

### **[뉴스 스크랩 설치 파일 받기 (zip)](https://github.com/min10256813-beep/news-scrap/releases/latest/download/NewsScrap-Setup.zip)**

zip 다운로드가 막히면 → [설치 파일(exe) 바로 받기](https://github.com/min10256813-beep/news-scrap/releases/latest/download/NewsScrap-Setup.exe)

## 설치 방법
1. 위 링크로 받은 zip 파일의 압축을 풉니다.
2. **`뉴스스크랩_설치.exe`** 를 더블클릭하면 끝입니다. (관리자 권한 필요 없음)
3. 바탕화면과 시작 메뉴에 **'민'** 아이콘의 **뉴스 스크랩**이 생깁니다.

> 파란색 **"Windows의 PC 보호"** 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요.
> 개인이 만든 프로그램이라 서명이 없어서 뜨는 안내입니다.

## 주요 기능
- **검색**: 중앙언론·지역언론 각 10건 (20·30건, 기간 선택). 제목에 검색어가 들어간 기사만 보여줌
  - 여러 표현은 쉼표(,), 빼고 싶은 단어는 앞에 `-`, 꼭 들어갈 단어는 앞에 `+`
  - 예) `대구경북 행정통합, TK통합 -신공항`
- **스크랩**: 별표로 저장 → [목록 복사]로 보고서에 붙여 넣기
- **키워드 알림**: 주기(5분 ~ 매일 08:30)를 정하면 새 소식이 생길 때 PC 알림. 같은 사건을 여러 신문이 보도하면 한 번만 알림
- **아침 브리핑**: 매일 정한 시각에 전날 퇴근 시각 이후 기사를 키워드별로 묶어서 알림
- **휴대폰 알림**: 무료 앱 ntfy 로 받기 (설정 화면 안내 참고)

## 참고
- **인터넷이 되는 PC**에서 사용하세요. (인터넷이 막힌 업무망 PC에서는 기사를 가져오지 못합니다)
- 창을 닫아도 오른쪽 아래 트레이(시계 옆)에서 계속 확인합니다. 완전히 끄려면 트레이의 '민' 아이콘 우클릭 → 종료
- 새 버전은 같은 링크에서 받아 다시 실행하면 업데이트됩니다. (키워드·설정 유지)
- 제거: 프로그램의 [설정] → [제거하기]
